What's new / Apa yang baru / Что нового

[ English ]

Infinity X:
• Finally all features from Infinity X 3.12 ported to 4.0
• Fixed Always-On Display while charging
• Fixed issues with the taskbar
• Properly removed ongoing call and screen recording Android chips when Dynamic Island is showing
• Removed duplicate incoming call heads-up notifications when Dynamic Island is active
• Added back support for removing the emergency button from the power menu
• Properly restored support for Ambient Pulse without overlapping lockscreen elements
• Enabled blur effects on more surfaces
• Added support for Icon Shapes

Kernel:
• MT6895 kernel sources by ESK Project
• BORE CPU scheduler backported from 6.12
• ThinLTO, PGO, BOLT, MLGO and Polly optimizations
• Compiled with the latest Clang 23.0.1
• And much more!

Infinity X:

• Устранены проблемы с таскбаром
